# 🎓 Epitech — Programme Grande École

📍 **Epitech Rennes, France**

🎓 **Programme Grande École**

📚 **2nd Year**

🗓️ **Class of 2030**

I'm currently studying in Epitech's **5-year Programme Grande École**, an intensive computer science curriculum centered around **project-based learning and autonomous problem solving**.

Rather than learning technologies primarily through traditional lectures, Epitech students learn by building increasingly complex projects.

The curriculum requires us to:

- Understand technical specifications
- Design software architectures
- Develop projects autonomously
- Work under strict technical constraints
- Respect coding standards
- Debug complex problems
- Collaborate through Git
- Work in teams
- Learn new technologies independently
- Manage projects and deadlines
- Review and improve our implementations

A large part of the curriculum is based around **C and Unix programming**, providing strong foundations in how software and computer systems work.

## ⚙️ Chocolatine

> **GitHub Actions · CI/CD · DevOps**

Chocolatine is an Epitech project focused on building a complete **CI/CD pipeline using GitHub Actions**.

The objective is to automate several operations around a repository.

The pipeline handles:

- Repository mirroring
- Coding-style verification
- Compilation
- Automated tests
- Repository validation
- CI automation

This project allowed me to explore **CI/CD concepts, GitHub Actions and development workflow automation**.

It also strengthened my interest in **DevOps engineering**.

---

## 🧩 Duo-Stumper

> **C · Algorithms · Problem Solving**

Duo Stumpers are intensive **4-hour programming challenges completed in pairs**.

The goal is to receive a technical specification and quickly:

1. Understand the problem
2. Design an algorithm
3. Implement the solution
4. Debug the program
5. Deliver a working implementation

All of this must be completed under strict time constraints.

The project develops skills around:

`C` · `Algorithms` · `Problem Solving` · `Teamwork` · `Time Management`
